Movie Recommendation System

Content-Based Filtering using TF-IDF & Cosine Similarity

1. Introduction

With the explosive growth of online streaming platforms, users are overwhelmed by a vast library of movies, making it difficult to find content matching their preferences. A Movie Recommendation System addresses this challenge by analyzing movie attributes and suggesting similar content based on a user's selection. This project implements a Hybrid Content-Based + Popularity Recommender that leverages Natural Language Processing (NLP) and Machine Learning to deliver accurate, real-time movie recommendations through an interactive web interface.

2. Problem Statement

To build an end-to-end machine learning system that recommends the top 5 most similar movies to a user-selected movie, based on metadata features such as genres, keywords, overview, and production companies, deployed as a web application with a visually engaging user interface.

3. Dataset

The project uses the TMDB 5000 Movie Dataset sourced from Kaggle, which contains metadata for 4,803 movies including:

4. Methodology

4.1 Data Preprocessing

JSON-encoded columns (genres, keywords, production_companies) are parsed and flattened. Multi-word terms are concatenated (e.g., "Science Fiction" → "ScienceFiction") to preserve meaning during tokenization. A unified tags column is created by concatenating: overview tokens + genres (×2 weight) + keywords + production companies. Text is lowercased and stemmed using the Porter Stemmer from NLTK.

4.2 Feature Extraction — TF-IDF Vectorization

The Term Frequency–Inverse Document Frequency (TF-IDF) technique converts each movie's tag string into a numerical vector. A vocabulary of 5,000 features is used with English stop-word removal:

TF-IDF(t, d) = TF(t, d) × log(N / DF(t))
where TF = term frequency in document d, DF = document frequency, N = total documents

This produces a sparse matrix of shape (4800 × 5000).

4.3 Similarity Computation — Cosine Similarity

Pairwise similarity between all movie vectors is computed using Cosine Similarity, producing a (4800 × 4800) similarity matrix:

cos(A, B) = (A · B) / (||A|| × ||B||) ∈ [0, 1]

A score of 1.0 indicates identical content profiles, while 0.0 indicates no similarity.

4.4 Hybrid Scoring

Pure content similarity is blended with a popularity component to avoid recommending obscure films:

Hybrid Score = 0.8 × Cosine Similarity + 0.2 × Normalized Popularity
where Popularity = vote_average × log(1 + vote_count)

7. Key Features

  • Real-time Autocomplete: Fuzzy search across 4,800 movie titles with keyboard navigation.
  • Hybrid Recommendations: Combines content similarity (80%) with popularity (20%) for balanced results.
  • Genre-Based Visual Posters: Dynamic gradient poster cards colored by genre (Action=Red, Sci-Fi=Blue, etc.).
  • Match Percentage: Each recommendation displays a similarity confidence score.
  • Responsive Design: Glassmorphic dark theme, works on mobile and desktop.
  • Quick Tags: Pre-defined genre buttons for instant recommendations.

8. Results & Evaluation

The model was tested with popular movies. Sample results demonstrate high-quality, contextually relevant recommendations:

The recommendations show strong genre and thematic coherence — Batman films are correctly grouped, sci-fi/adventure films cluster together, and drama/romance films appear in relevant groupings. The hybrid scoring ensures popular, well-rated films are ranked higher.

9. Conclusion & Future Scope

This project successfully demonstrates an end-to-end ML pipeline: from data preprocessing and feature engineering to model deployment via a web application. The TF-IDF + Cosine Similarity approach provides interpretable, fast recommendations without requiring user interaction history (cold-start friendly).

Future Improvements:

  • Integrate Collaborative Filtering using user ratings for personalized recommendations.
  • Add TMDB API integration for real movie poster images.
  • Deploy on cloud platforms (Heroku / AWS / Render) for public access.
  • Incorporate deep learning embeddings (Word2Vec / BERT) for semantic understanding.
